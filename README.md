## 📌 Sobre o Repositório

Este repositório documenta minha evolução na resolução de problemas algorítmicos e na aplicação de estruturas de dados através da plataforma [Beecrowd](https://www.beecrowd.com.br/). 

Para enriquecer o estudo de diferentes paradigmas, todos os problemas são solucionados utilizando duas linguagens:
- **Java:** Focado em tipagem forte, orientação a objetos e estruturação robusta.
- **Python:** Focado em scripts concisos, prototipagem rápida e legibilidade.

A premissa principal não é apenas resolver o problema, mas aplicar princípios de **Clean Code**, garantindo soluções legíveis, eficientes e bem estruturadas.
